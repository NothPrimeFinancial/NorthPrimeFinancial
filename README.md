# North Prime Financial - Premium Wealth Site

Site estático pronto para Vercel, Netlify ou Cloudflare Pages.

## Arquivos
- index.html
- styles.css
- script.js
- assets/logo-header.svg
- assets/logo-footer.svg
- assets/favicon.svg

## Publicar na Vercel
1. Crie um repositório no GitHub chamado `north-prime-financial`.
2. Envie todos estes arquivos para o repositório.
3. Na Vercel, clique em `Add New Project` e importe o repositório.
4. Framework Preset: `Other` ou `Static`.
5. Build Command: deixe em branco.
6. Output Directory: deixe em branco ou use `./`.
7. Clique em Deploy.
